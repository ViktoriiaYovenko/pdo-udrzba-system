# Návrh systému podpory údržby a provozního plánování

## 📌 Popis projektu
Projekt představuje návrh jednoduchého informačního systému pro evidenci poruch výrobních zařízení a podporu rozhodování v oblasti údržby a provozního plánování.

Systém je určen pro malou sociální výrobní organizaci zaměřenou na ruční výrobu (šití, práce se dřevem, výtvarná činnost).

---

## 👥 Cílová skupina

| Role                     | Popis |
|--------------------------|------|
| Vedoucí organizace       | Přehled o provozu |
| Správce provozu          | Řízení poruch a oprav |
| Údržbář                  | Provádění oprav |
| Administrativní pracovník| Zadávání dat |
