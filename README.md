# Návrh systému podpory údržby a provozního plánování

## Popis projektu
Tento projekt představuje návrh jednoduchého informačního systému pro evidenci poruch výrobních zařízení a podporu rozhodování v oblasti údržby a provozního plánování.

Systém je určen pro malou sociální výrobní organizaci zaměřenou na ruční výrobu (šití, práce se dřevem, výtvarná činnost).

Součástí návrhu je analytický modul, který na základě historických dat vyhodnocuje četnost poruch a doporučuje preventivní zásahy.

## Cílová skupina
- Vedoucí organizace  
- Správce provozu  
- Údržbář  
- Administrativní pracovník
